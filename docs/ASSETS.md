# Wartide artwork assets

## Generating images with Google Antigravity CLI (`agy`)

```sh
export PATH=$PATH:/Users/lcwl/.local/bin
cd assets/raw
agy -p "Generate an image: <description>. Save it in the current directory as exactly <name>.png (PNG)." \
    --dangerously-skip-permissions --add-dir "$PWD" --print-timeout 5m --model gemini-3.8-flash-low
```

- Works non-interactively; takes ~30-90 s per image. The agent delegates to an `image-generator`
  subagent (nano banana). Output is 1024x1024 (wordmark 2400x800, texture 512x512).
- The file is written into the working directory under the name you request in the prompt
  (without a name it picks its own; `~/gemini` was only where the earlier manual test landed).
- On quota/other failures the agent may fall back to writing Python/SVG scripts; delete such strays.
- Parallel runs work, but the account has a quota: after ~14 images a 429
  `RESOURCE_EXHAUSTED (Individual quota reached ... resets in ~168h)` appeared and all further calls fail.

## Quality notes
- Silhouettes are clean and crisp (level-threshold gives sharp edges); fighter has thin internal
  outline lines (reads like a P-51-style plane, fine but fairly "real"); bomber is somewhat odd
  (a big transport-like hull with a few props); submarine is small/flat in the 64px size.
  Battleship and carrier are clearly readable. Consider hand-drawn SVG for bomber and submarine.
- Japan roundel has radiating rays reminiscent of a historical flag; consider replacing with a more
  abstract motif if that is a concern. Roundels have white backgrounds (not transparent); cropped to 256px.

## License / originality
All images were generated by an AI model from original generic prompts. No trademarked game logo, box art,
board or sculpt silhouettes were requested, and no national insignia (e.g. swastikas) were used.
Review before release; AI output copyright status varies by jurisdiction.

## Vector icon set (assets/icons)
Hand-authored SVGs replacing the inconsistent AI PNGs. `units/<id>.svg` (10 unit silhouettes, 64x64 viewBox,
`fill="currentColor"`, so colour them via CSS `color`), `powers/<id>.svg` (5 circular roundels with fixed power
colours and cream geometric motifs: star, plain Greek cross, chevron, plain disc, star-in-ring), and `sprite.svg`
(`<symbol id="unit-infantry">`, `power-ussr`, ... for `<use href="assets/icons/sprite.svg#unit-armor">`).
`preview.html` / `preview.svg` show all icons at 64px and 20px in each power colour. All designs are original
and generic; no historical insignia.
