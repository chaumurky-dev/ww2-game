# Wartide

An online, play-by-web global WWII strategy game for 1–5 players (humans and computer
players), built almost entirely in Rust: a deterministic rules engine, an axum server,
and a Leptos/WASM web client.

Game mechanics follow the classic 1986 five-power design exactly (see `docs/RULES.md`);
all artwork, names and text are original.

See `CLAUDE.md` for the repo layout and `docs/ARCHITECTURE.md` for the design.
